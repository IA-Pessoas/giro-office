# Aplicar as novas invariantes sem migrar tarefas existentes

Novas tarefas de projeto deverão usar um modelo do mesmo departamento e somente poderão apontar
para um líder ou administrador elegível, permanecendo sem responsável quando nenhum existir.
Registros anteriores incompatíveis serão preservados; as invariantes passam a valer na criação ou
quando os campos relacionados forem alterados.
